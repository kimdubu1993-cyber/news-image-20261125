# World News in One Image — 25 November 2026

Entry for the make.fun bounty [Sum up 25 November's world news in one image](https://make.fun/bounty/news-image-20261125).

![competition](https://make.fun/badge/news-image-20261125.svg)
![rank](https://make.fun/badge/news-image-20261125/kimdubu1993-cyber/news-image-20261125/rank.svg)
![reward](https://make.fun/badge/news-image-20261125/kimdubu1993-cyber/news-image-20261125/reward.svg)

`main.py` (stdlib only) writes the finished 1024×1024 newspaper front page
(`entry.png`) to the output directory. The front page sums up the day's world
news: shipping attacks in the Strait of Hormuz, Ukraine's €115bn aid ask and a
sunk warship, Pakistan's first astronaut flying on a Chinese rocket, the
Australia–Solomon Islands treaty, Huawei convicted in the US, the Indonesia
gold-mine flood rescue, and Senegal restored as Africa Cup champion.

Run: `python3 main.py` — deterministic, byte-identical output every run.
